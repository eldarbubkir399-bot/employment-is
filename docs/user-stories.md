# User Story

Құрылымы: **Мен [рөл] ретінде, [мақсатты] орындағым келеді, себебі [пайдасы].**

| ID | User Story | Талап |
|---|---|---|
| US-01 | Мен жұмыс іздеуші ретінде, резюмені онлайн жасап жаңартқым келеді, себебі орталыққа барып қағаз толтырмауым керек. | FR-03 |
| US-02 | Мен жұмыс іздеуші ретінде, бос орындарды мамандығы мен өңірі бойынша іздегім келеді, себебі өзіме сай жұмысты жылдам табуым керек. | FR-05 |
| US-03 | Мен жұмыс іздеуші ретінде, өзіме сәйкес жаңа бос орындар туралы хабарлама алғым келеді, себебі қолайлы ұсынысты өткізіп алмауым керек. | FR-06, FR-09 |
| US-04 | Мен жұмыс іздеуші ретінде, бос орынға өтініш беріп, оның күйін көргім келеді, себебі жауап күтіп бейхабар қалмауым керек. | FR-07 |
| US-05 | Мен жұмыс беруші ретінде, бос орынды жариялағым келеді, себебі қажетті қызметкерді тез табуым керек. | FR-04 |
| US-06 | Мен жұмыс беруші ретінде, өтінімдерді бір жерде қарап шешім қабылдағым келеді, себебі іріктеуге аз уақыт жұмсауым керек. | FR-08 |
| US-07 | Мен орталық маманы ретінде, жалған не мерзімі өткен бос орындарды модерациялағым келеді, себебі жүйедегі ақпарат сенімді болуы керек. | FR-11 |
| US-08 | Мен орталық маманы ретінде, өңір бойынша жұмыспен қамту есебін алғым келеді, себебі көрсеткіштерді бақылап шешім қабылдауым керек. | FR-12 |
