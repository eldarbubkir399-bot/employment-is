# Жүйеге қойылатын талаптар

Жоба: **Жұмыспен қамту ақпараттық жүйесі**.

## 1. Stakeholder-лер

| № | Stakeholder | Мүддесі / күтуі | Ықпалы |
|---|---|---|---|
| 1 | Жұмыс іздеушілер | Қолайлы жұмысты тез табу, орталыққа бармай өтініш беру | Жоғары |
| 2 | Жұмыс берушілер | Қажетті қызметкерді жылдам табу, іріктеуге аз уақыт жұмсау | Жоғары |
| 3 | Жұмыспен қамту орталығының мамандары | Қолмен жұмысты азайту, ақпараттың сенімділігін бақылау | Жоғары |
| 4 | Жергілікті атқарушы орган / уәкілетті мемлекеттік орган | Жұмыспен қамту көрсеткіштерін бақылау, нақты статистика | Жоғары |
| 5 | Сыртқы жүйе провайдері (e-gov / ЭЦҚ) | Қауіпсіз әрі стандартқа сай интеграция | Орташа |
| 6 | Әзірлеуші және техникалық қолдау тобы | Анық талаптар, жүйенің тұрақты жұмысы | Орташа |

## 2. Функционалдық талаптар

| ID | Талап | Басымдық |
|---|---|---|
| FR-01 | Жүйе пайдаланушыны (жұмыс іздеуші, жұмыс беруші) тіркеуге және логин/құпиясөзбен жүйеге кіргізуге тиіс. | Жоғары |
| FR-02 | Жүйе жұмыс іздеушінің жеке басын сыртқы жүйе (e-gov / ЭЦҚ) арқылы растауы тиіс. | Жоғары |
| FR-03 | Жұмыс іздеуші резюмені жасай, өзгерте және оның көрінуін (ашық/жасырын) басқара алуы тиіс. | Жоғары |
| FR-04 | Жұмыс беруші бос орынды жариялай, өзгерте және жаба алуы тиіс. | Жоғары |
| FR-05 | Жүйе бос орындарды мамандық, өңір, жалақы және жұмыс түрі бойынша іздеуге және сүзуге мүмкіндік беруі тиіс. | Жоғары |
| FR-06 | Жүйе резюме мен бос орынның сәйкестігі бойынша қолайлы бос орындарды автоматты ұсынуы тиіс. | Орташа |
| FR-07 | Жұмыс іздеуші бос орынға өтініш беріп, өтініш күйін көре алуы тиіс. | Жоғары |
| FR-08 | Жұмыс беруші өтінімдерді қарап, шешім (сұхбатқа шақыру / қабылдау / бас тарту) қабылдай және бас тарту себебін көрсете алуы тиіс. | Жоғары |
| FR-09 | Жүйе өтініш жіберілгені, шешім қабылданғаны және жаңа сәйкес бос орын туралы хабарлама жіберуі тиіс. | Орташа |
| FR-10 | Жұмыс іздеуші жіберілген өтінішті қайтарып ала алуы тиіс. | Төмен |
| FR-11 | Орталық маманы жалған не мерзімі өткен бос орындарды модерациялай және пайдаланушыны бұғаттай алуы тиіс. | Орташа |
| FR-12 | Жүйе өңір және мамандық бойынша бос орындар, өтініштер мен жұмысқа орналасу статистикасы бойынша есеп қалыптастырып, PDF/Excel форматына экспорттауы тиіс. | Орташа |

## 3. Функционалдық емес талаптар

| ID | Санат | Талап |
|---|---|---|
| NFR-01 | Өнімділік | Іздеу сұрауына жауап ≤ 3 секунд; бір мезгілде кемінде 2000 пайдаланушымен жұмыс. |
| NFR-02 | Қолжетімділік | Жүйе айына кемінде 99,5% уақыт жұмыс істеуі тиіс. |
| NFR-03 | Қауіпсіздік | Деректер TLS арқылы беріледі; құпиясөздер хэштеліп сақталады; ЖСН және байланыс деректері шифрланады; рөлдік қолжетімділік. |
| NFR-04 | Қолдану ыңғайлылығы | Интерфейс қазақ және орыс тілдерінде; өтініш беру ең көп дегенде 3 қадамда; веб-интерфейс қолжетімділік стандарттарын (WCAG) ескереді. |
| NFR-05 | Сенімділік | Деректердің күнделікті резервтік көшірмесі жасалады; жүйе ақауынан кейін қалпына келтіру уақыты ≤ 4 сағат. |
| NFR-06 | Масштабталу | Жаңа өңір, жаңа мамандық классификаторы код өзгертпей, конфигурация арқылы қосылады. |
| NFR-07 | Жеке деректерді қорғау | Дербес деректерді өңдеу Қазақстан Республикасының заңнамасына сәйкес жүргізіледі; сақтау мерзімі шектеледі. |
