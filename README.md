# Жұмыспен қамту ақпараттық жүйесі

Жұмыс іздеушілер мен жұмыс берушілерді онлайн біріктіретін, бос орындарды жариялау, резюме жасау, іздеу, өтініш беру және іріктеу процестерін автоматтандыратын ақпараттық жүйе жобасы.

> Оқу жобасы: «Ақпараттық жүйелерді жобалау» зертханалық жұмыстары (ЗС №1–5).

## Жүйенің мақсаты

Жұмыс іздеуші мен жұмыс берушіні бір платформада біріктіру, жұмыспен қамту орталығының қолмен жасалатын жұмысын автоматтандыру арқылы жұмысқа орналасу уақытын қысқарту және жұмыспен қамту көрсеткіштерін бақылауды жақсарту.

## Негізгі пайдаланушылар

| Пайдаланушы | Рөлі |
|---|---|
| Жұмыс іздеуші | Резюме жасайды, бос орындарды іздейді, өтініш береді |
| Жұмыс беруші | Бос орын жариялайды, өтінімдерді қарап шешім қабылдайды |
| Орталық маманы | Бос орындарды модерациялайды, есеп қалыптастырады |
| Сыртқы жүйе (e-gov / ЭЦҚ) | Жеке басты растайды |

## Негізгі компоненттер

1. Пайдаланушы интерфейсі (веб-портал, мобильді нұсқа)
2. Авторизация және аутентификация модулі
3. Резюме және профиль модулі
4. Бос орындар модулі
5. Іздеу және сәйкестендіру модулі
6. Өтініштер модулі (негізгі бизнес-процесс)
7. Хабарламалар модулі
8. Есеп беру модулі
9. Әкімшілік басқару және модерация модулі
10. Дерекқор
11. Сыртқы жүйелермен интеграция модулі
